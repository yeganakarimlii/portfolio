Security Awareness & Mail Infra CASE #01

Daxili Fişinq Simulasiyası (GoPhish + Postfix) və Əməkdaşların Maarifləndirilməsi

Problem: Şirkət daxilində sosial mühəndislik və fişinq e-poçtlarına qarşı əməkdaşların həssaslıq səviyyəsini ölçmək və insan faktorundan yaranan təhlükəsizlik boşluqlarını aşkarlamaq.

Həll & İcra: RHEL Linux serveri üzərində Postfix Mail Transport Agent qurularaq GoPhish platforması ilə inteqrasiya edildi. Realistik daxili bildiriş ssenarisi ilə test kampaniyası aparıldı. Nəticələrə əsasən 12 bölməlik "Kibercinayət hücumlarından qorunma" təlim təqdimatı hazırlanaraq əməkdaşlara domen yoxlanışı, HTTP/HTTPS fərqi və insident bildirişi qaydaları izah edildi.

Windows Server & IAM Hardening CASE #02

Active Directory OU Strukturu və Group Policy (GPO) Təhlükəsizlik Sərtləşdirilməsi

Problem: Müxtəlif şöbələr üzrə işçi stansiyalarının vahid təhlükəsizlik standartına gətirilməsi, icazəsiz USB daşıyıcıları və komanda sətirləri vasitəsilə yarana biləcək risklərin qarşısının alınması.

Həll & İcra: Departament əsaslı OU ağacı (Credit, Finance, HR, IT, PK, RISK, PC, SERVER) təşkil edildi. USB_BLOCK, CMD_BLOCK, POWERSHELL_BLOCK və PASSWORD_POLICY (min. 8 simvol, mürəkkəblik, 5 səhv cəhddən sonra bloklanma) tətbiq olundu. İstifadəçilərin şifrə qaydalarını daim görməsi üçün xüsusi korporativ Lockscreen və Wallpaper GPO-ları yayıldı.

Reverse Proxy & Zero-Trust Access CASE #03

NGINX Reverse Proxy və Cloudflare Tunnel ilə Daxili Xidmətlərin Təhlükəsiz Nəşri

Problem: Lokal serverdə və Docker konteynerlərində işləyən daxili veb tətbiqlərə kənardan təhlükəsiz giriş təmin etmək, lakin router/firewall üzərində açıq inbound portlar (80/443 port forwarding) saxlamamaq.

Həll & İcra: Daxili xidmətlər Docker konteynerlərində izolyasiya edildi və qarşısında NGINX Reverse Proxy konfiqurasiya olunaraq domen əsaslı yönləndirmə (virtual host routing) quruldu. Cloudflare Tunnel (cloudflared) inteqrasiyası ilə serverin real IP ünvanı tam gizlədildi və şifrələnmiş outbound tunel üzərindən DDoS/WAF qorumalı giriş əldə edildi.

Trafik Axını (Zero Inbound Ports):
İstifadəçi CF Tunnel NGINX Docker
NGINX Cloudflare Tunnel Docker
Network Security & Enterprise VoIP CASE #04

FortiGate 7.4 Firewall Siyasətləri, Nmap Təhlükəsizlik Auditi və Yeastar PBX İnteqrasiyası

Problem: Korporativ şəbəkə perimetrinin zəifliklərdən qorunması, açıq portların nəzarət altına alınması, uzaqdan təhlükəsiz girişin təmin edilməsi və daxili IP telefoniya infrastrukturunun fasiləsiz işləməsi.

Həll & İcra: FortiGate 7.4 və pfSense firewall platformalarında trafik filtrləmə siyasətləri və şifrələnmiş VPN tunelləri sazlandı. Nmap ilə şəbəkə skanlanması və açıq port auditi aparılaraq zəifliklər aradan qaldırıldı. Həmçinin Yeastar PBX IP telefoniya və DFS fayl paylaşımları təhlükəsiz şəkildə inteqrasiya edildi.

Perimetr & Korporativ Servis Struktur:
FortiGate 7.4 Policy & VPN
Nmap Audit Port & Vuln Scan
Yeastar PBX Enterprise VoIP
FortiGate 7.4 pfSense / Nmap Yeastar PBX
