Security Awareness & Postfix CASE #01

GoPhish + Postfix Simulasiyası və Maarifləndirmə Təlimi

Problem: Şirkət daxilində fişinq e-poçtlarına qarşı həssaslığın ölçülməsi və əməkdaşların təhlükəsiz davranış vərdişlərinin artırılması.

Həll & İcra: RHEL mühitində Postfix mail serveri və GoPhish qurulmaqla simulasiya kampaniyası keçirildi. Ardından 12 slaydlıq maarifləndirici təqdimat hazırlanaraq domen yoxlanışı, şifrə siyasəti, MFA və insidentlərin bildirilməsi izah olundu.

Docker & NGINX Reverse Proxy CASE #03

Docker Konteynerləri və NGINX Reverse Proxy Quraşdırılması

Problem: Bulud mühitində veb tətbiqin Docker konteynerində izolyasiyalı işlədilməsi, DNS sazlamaları və NGINX vasitəsilə domen üzərindən nəşri.

Həll & İcra: Azure-da Docker və NGINX VM-ləri ayrıldı, docker compose up -d ilə konteyner başladıldı, DNS A qeydi ilə gridx.digital canlıya çıxarıldı.

Firewall, Audit & VoIP CASE #04

FortiGate 7.4 Firewall, Nmap Auditi və Yeastar PBX İnteqrasiyası

Problem: Şəbəkə trafikinin nəzarətdə saxlanılması, açıq port və xidmətlərin yoxlanılması, həmçinin daxili IP telefoniya rabitəsinin sabit işləməsi.

Həll & İcra: FortiGate və pfSense firewall qaydaları sazlandı, Nmap ilə şəbəkə skan/audit işləri aparıldı və Yeastar PBX IP telefoniya sistemi konfiqurasiya edildi.
